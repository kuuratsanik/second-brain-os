---
description: Preview a run without writing
argument-hint: "[task]"
disable-model-invocation: true
---

Do the task described in $ARGUMENTS (a skill or command name, or a plain description) as a dry run. Read the vault and follow that task's own skill to decide what it would do, but write nothing, move nothing and commit nothing. Report every page you would create, update, merge or archive, every link you would add, and every path a run commit would contain. Mark anything that would need the owner's approval.
