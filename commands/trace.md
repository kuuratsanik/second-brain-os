Same as `/ask` for $ARGUMENTS, with the reading trail added: after the answer, list every page read, in the order opened, with what each contributed and which ones the answer did not end up using. Use it to check how an answer was built; use `/ask` when you only want the answer.

Follow the `second-brain-ask` skill.
