# archive/

Pages retired by a merge, prune or archive pass. Nothing is ever deleted: a
retired page moves here with its original path (`archive/wiki/concepts/x.md`)
and frontmatter that says when it was archived, why, where it came from and, for
a merge, which page absorbed it. Archived pages stay on disk and searchable but
are not listed in `wiki/index.md`. To restore one, move it back and remove the
`archived*` fields.
