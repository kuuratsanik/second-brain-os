# Note linking

> Fictional. This page belongs to the demo vault; the people, organisations and articles in it are invented.

## In one paragraph

Writing a link to a related note at the moment a sentence is written, so that each note can be reached from at least one other. A note nobody links to is, in practice, lost.

## Where it came from

[[2026-09-29-notes-that-link-back|Notes that link back]], a talk by an invented speaker. It is the only source for this page so far.

## What supports it

- The speaker's own account of writing with backlinks visible, using [[margin|Margin]].
- The orphan rate of this vault, measured by the script described in the demo README, stays at zero as long as each new page is linked from its hub.

## What argues against it

- The talk is one person's practice, with no measurement.

## Open questions

- Is a link worth writing when the target is a hub page and not a related idea? Not covered by any source here.
